# Stage collage images

Three per stage, named `<stage>-1.jpg`, `<stage>-2.jpg`, `<stage>-3.jpg`.
**Square, 800×800 or larger, .jpg.** Drop them in — nothing else to wire up.

Shared style to append to every prompt, so the 27 images read as one set:

> Muted desaturated palette of deep navy and warm off-white, soft directional
> light, film grain, shallow depth of field, editorial photography, no text, no
> logos, no watermarks, square composition.
